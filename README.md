## 🚀 Como executar o projeto

1. Certifique-se de estar na pasta do projeto:

```bash
cd projeto-To-Do-List
````

2. Instale as dependências (somente na primeira vez que rodar):

```bash
npm install
```

3. Execute o servidor de desenvolvimento:

```bash
npm run dev
```

4. Após rodar o comando acima, o terminal exibirá um link parecido com:

```
  Local:   http://localhost:5173/
```

5. Abra esse link no navegador para visualizar a aplicação.

---

## 📌 Observação

* A pasta `node_modules/` não está incluída no repositório, mas será criada automaticamente após o comando `npm install`.
* Caso precise encerrar o servidor, basta pressionar `CTRL + C` no terminal.
